# RDV app icons

`rdv-wordmark.svg` is the canonical starless RDV wordmark. Reuse it whenever RDV is shown as a wordmark; do not recreate RDV with a system typeface. It is derived from the official hotel logo with the decorative star removed.

`rdv-order-icon.png` is the canonical artwork for the RDV Order app. Reuse this exact file whenever the ordering app needs an icon; do not introduce a second copy or redraw it.

`rdv-order-icon.webp` is the 256px optimized delivery image used by the download page.

`rdv-staff-service-icon.png` is the canonical artwork for RDV Team. Reuse this exact file whenever the team app needs an icon; do not introduce a second copy or redraw it.

`rdv-staff-service-icon.webp` is the 256px optimized delivery image used by the download page.

The Android app still uses its existing packaged launcher icon. Replacing that launcher icon requires a new signed APK release and is intentionally outside this download-page-only change.
