# Architecture

## 新增核心流程

1. 登录后服务员进入 `/tables` 图形化选桌页。
2. 选择绿色桌开台并填写人数，或选择两张绿色桌拼桌开台。
3. 进入 `/order` 点餐页按分类下单。
4. 在点餐页查看已点餐品与总价。
5. 点击结账确认，系统自动关台并返回选桌。

## 数据模型

- `table_sessions`
  - 开台记录（桌号、人数、开台时间、关台时间）
- `table_session_tables`
  - 开台桌号映射（支持拼桌：一个 session 对应两张基础桌）

## 颜色状态

- 绿色：未开台（可开台）
- 红色：已开台（可继续点餐或结账）

## 关键页面

- `/tables`：选桌与拼桌
- `/order`：点餐 + 已点餐品 + 结账
